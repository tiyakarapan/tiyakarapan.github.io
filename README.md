# My Portfolio

### Setup

#### Node

- Download and install nvm: `https://github.com/coreybutler/nvm-windows/releases/download/1.2.2/nvm-setup.exe`
- Install latest node version: `nvm install lts`
- Use latest node version: `nvm use lts`

#### Package

- Install dependencies: `npm install`
- Run Local: `npm run start`
