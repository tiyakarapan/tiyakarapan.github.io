My Past Projects

Pomodoro Timer - a timer website application that allows a user to start a timer, with a minimum time period of 20 minutes. The user can add or remove time by intervals of 5 before the timer starts, but once the timer has been started, the user may not remove any time, only add additional time. The timer also has a quote rotator implemented to keep the user motivated. These quotes change every 5 minutes.

To-Do List - a to-do list website application that allows a user to keep track of their short-term tasks. The user can input their task and click "Add" to add their task to the list. From there, the user can either choose to mark the item as complete or delete it from the list. It is important to note that the to-do list will only be saved for as long as the user keeps the application open.
